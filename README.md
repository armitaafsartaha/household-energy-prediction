# Household Energy Consumption Prediction 🔋

This project applies **Multiple Linear Regression** to predict household energy consumption (kWh) based on various household features.

## Features
- Data preprocessing (drop unnecessary columns, label encoding)
- Model training and testing with scikit-learn
- Evaluation using MAE, RMSE, R², Adjusted R², and F-test
- Correlation heatmap visualization

## Results
- High model accuracy with R² ≈ 0.98
- Features such as appliance usage and AC presence strongly influence energy consumption
